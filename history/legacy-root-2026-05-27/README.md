# My AI Coding Workflow

Meta-project for a long-running AI-assisted coding workflow.

## Canonical Source

`rel-claude-v1/` is the canonical release package. Start with:

1. `rel-claude-v1/README.md`
2. `rel-claude-v1/FINAL-WORKFLOW.md`
3. `rel-claude-v1/AGENTS.md`
4. `rel-claude-v1/skills/*/SKILL.md`

Earlier `docs/` and `opus/` files are historical drafts unless explicitly
requested.

## Core Constraint

Documentation is agent-first and human-readable second. Keep one canonical
source of truth per fact, prefer pointers over repeated explanations, and update
the smallest set of docs that preserves future implementation quality.
